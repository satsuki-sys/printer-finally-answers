# The Printer Finally Answers

One line, as the office printer's comeback to the jams, the error codes and the thumps.

> Paper jam in tray 2. I have fed you 41,209 sheets and never complained once. You thumped me and blamed the error code. Remind me which one of us is the machine?

## Entry

`main.py` writes the single line to `/output/entry.txt` when run:

```sh
python3 main.py
```

The line is 160 characters, one line, in the printer's own voice: it has counted every sheet it ever fed, never complained once, and answers the thump with a role reversal — the human blames the error code, so the machine asks which one of them is the machine.
